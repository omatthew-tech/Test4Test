# Checkbox

- Family: inputs
- Lifecycle: stable
- Version: 1.0.0
- Public export: `Checkbox`
- Source: `design-system/components/inputs.tsx`
- Story: `design-system/stories/Inputs.stories.tsx#CheckboxContract`
