# Typography

Geist Variable is the interface and content family. Geist Mono Variable is limited to identifiers, logs, code, and technical values. Use weights 400, 500, and 600 routinely; reserve 700 for rare emphasis. Body copy should remain between 55 and 75 characters per line. Use sentence case and tabular numerals for aligned values.

Interfaces must reflow without loss at 200% text enlargement and 320 CSS px.
