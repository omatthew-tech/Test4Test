# Homepage spacing consistency mockups

Three desktop image mockups based on the current local homepage, captured at 1440 × 900.

- [01 — Compact](01-compact.png): tighter spacing between sections and related elements.
- [02 — Balanced](02-balanced.png): moderate, consistent spacing throughout; recommended.
- [03 — Relaxed](03-relaxed.png): more breathing room with a consistent section rhythm.

Scope: spacing-only design exploration. Application source, design-system tokens, behavior, and visual baselines were not edited.

The existing page was inspected at desktop 1440 × 900 and mobile 390 × 844. The existing desktop CSS gives adjacent sections 128 px padding each, producing 256 px content gaps. The prompts use the existing semantic spacing scale to reduce these accumulated gaps.

Created with the built-in image-generation tool. These are AI-rendered mockups, not exact browser renders of proposed CSS. Small text, illustration details, dimensions, and spacing can vary from the reference. Visual review checked section order, primary copy, desktop composition, and the trust row. Incorrect trust-row content in initial drafts was corrected using the actual screenshot. Final images include the entire page through the footer.

No implementation checks or release gates were run because no interface implementation was changed. Spacing token values in the prompts are design intent, not measured output specifications.

[Exact generation and correction prompts](generation-prompts.md). Source screenshots are included alongside the final images; the mobile capture is reference only.
