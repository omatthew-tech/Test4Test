# Performance implementation — 10 September 2026

These changes preserve the current screens, media, wording, routes, ranking rules, export contents and access permissions. They are implemented in the repository; no production deployment or database migration has been run.

The common production startup dependency graph decreased from 562,700 to 512,159 bytes of JavaScript (9.0%), and from 150,041 to 119,907 bytes of CSS (20.1%). Gzip totals decreased from 162,126 to 146,812 bytes of JavaScript and from 19,815 to 15,945 bytes of CSS. These are build measurements, excluding route-specific lazy chunks; they are not measured improvements to live page load time. The homepage still downloads its own content when visited.

Deployment requires the three new SQL migrations, updated Supabase functions, the video worker and a frontend build. Batched upload signing is capability-negotiated, and transcript deltas have an old-RPC fallback. Database operations should follow the existing project release process; production performance and query plans have not been benchmarked with these changes.

Validation: 101 unit tests, 71 component tests, 18 Supabase logo tests, 19 worker tests and four production hydration/font checks passed. Application and worker type checks, Supabase entry-point checks, design-system invariants, build and bundle budgets passed. Eighteen direct comparisons against the pre-change source (nine routes at 390 × 844 and 1440 × 900) produced byte-identical screenshots. No visual baselines were changed.

The complete release gate was attempted and stopped at the existing browser suite: 183 checks passed and ten failed. Two failures concern contrast in the deliberately faded homepage cards/caption (also reached by the fallback route). The other eight expect older homepage structure, the navigation label “Analytics” instead of the current “Analyze”, or the previous recording-link labels. Those product choices and the old test expectations were not changed as part of this performance work. The later full Storybook screenshot stage was not reached; the direct before/after comparisons above separately verified the affected appearance. Lint reports 19 existing hook-dependency warnings and no errors.
